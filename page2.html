Impact of Web Browsers on Internet Usage



People had a new way to access information and communicate across the world. The way people interacted with computers was forever changed allowing us to use efficient search engines to browse the web and access important information.


The birth of web browsers took the world by storm in the highly eventful 1990s. Starting most pivotally in the 1970s and continuing through the 90s, IBM were active in development of over 33 closed and private networks. Until 1983, when IBM’s Information Network became the first open network. Thousands of public and private networks were invented and available for the public, 80% of which specifically used IBM’s SNA (Systems Network Architecture), which had been initiated in 1974. This changed once IP was made available for everyone in 1996 (History of the Internet, 2024).


The emergence of web browsers first began when the World Wide Web browser was created. Initiated by Tim Berners-Lee in 1989, a British scientist set the stage for the completion of the first ever web browser, via the European Organization for Nuclear Research (CERN) project. The World Wide Web project was called ENQUIRE at the time, and in 1990, the world's first website and server went live running on Berners-Lee's NeXT computer, at CERN. It was a revolutionary project. And in the same year, McGill University student Alan Emtage developed Archie - it is considered the first Internet search engine (Pew Research Center, 2014). Following this eventful year, many people began to grow more familiar with the idea of utilizing web browsers and searching files and information over the Internet. The World Wide Web was a sensational innovation as it was the first web browser developed with a user-friendly interface. Enter browsers Mosaic, Netscape, and Internet Explorer, in 1993, 1994, and 1995 respectively (GeeksforGeeks, 2023).


(Image of the NeXT Computer)


Mosaic was a pioneering web browser invented by NCSA (National Center for Supercomputing Applications) in 1993. It gained significant traction among computer users and was the very first graphical browser which was capable of displaying multimedia on the web (GeeksforGeeks, 2023). It was revolutionary in laying the foundation for modern internet browsing. “One of Mosaic's creators, Marc Andreessen, later co-founded Netscape Communications Corporation, further contributing to the development of web browsers,” Johnson notes. The following year, Andreessen and his co-workers at NCC invented Netscape Navigator, which worked as another modern web browser with not only a user-friendly interface but novel features like JavaScript support and tabs. It was developed with a special source code that was later made open-source, leading to the initiation of the Mozilla project. Therefore, despite Netscape Navigator discontinuing in 2008, its legacy lives on in the form of Mozilla Firefox. Mozilla Firefox remains a heavily popular web browser in the 21st century. The year that followed Netscape Navigator's invention, 1995, Microsoft developed Internet Explorer. This browser became the default web browser for millions of users around the world due to the integration it had with the Windows operating system. Microsoft achieved over 90% of a market share for Internet Explorer, when operating at its peak, but it was later discontinued due to heavy competition from other browsers as well as major security concerns (Johnson, 2023). Microsoft Edge took its place after, and operated as a competing web browser alongside Google Chrome and Mozilla Firefox (GeeksforGeeks, 2023).


However, before the modern period of web browsers of the early 2000s, namely Mozilla Firefox, Chrome, and Microsoft Edge, Internet Explorer and Netscape were the major competing browsers in the “browser wars” of the mid- to late-90s. They were sought after for their adapted, attractive new version releases developed through the years, as well as their high popularity and top-quality user interfaces, ahead in the industry. Opera Software attempted to join the browser wars with the release of the Opera web browser, which is still running and being used to this day (GeeksforGeeks, 2023). The Norwegian company, Opera Software, succeeded in attaining a “loyal user base” due to its innovative adoption of tabbed browsing and efficient rendering. It was also the first major web browser to include an ad blocker, built into the browser, offering better speed and privacy when browsing the internet (Johnson, 2023).


Following Netscape's decision to make its code open source in 1998, Mozilla was born. It later evolved into the Mozilla Firefox web browser which gained heavy attraction by users worldwide. Several years later, in 2008, major tech company Google founded Google Chrome. According to an article in 2023 by GeeksforGeeks, “[Google Chrome] attracted users all across the globe because of its high-speed rendering, improved web performance and well-designed interface.” It swarmed into existence and took over the entire web browsing market; “to date it has maintained its position as the most used web browser.” Even more years later, in 2015, Windows invented Micorosfot Edge. Today, Microsoft Edge is preinstalled in most Windows devices and is adored by many users for its unique features, high-quality usability, and elegant user-interface (GeeksforGeeks, 2023).


By this time, web browsers had significantly evolved to support a lot more features besides only searching the internet. Better standards compliance as well as improved user experiences were at the center of the development of modern era internet browsers. Web development features brought by HTML4 and HTML5 significantly pushed forward the support for web applications such as web browsers. HTML4, released in 1997 brought features like tables, forms, and framesets, while HTML5, which was introduced in 2014, brought extensive additions like the following elements: canvas, video, audio, header, footer, and more. It also introduced the support for local storage, improved form validation, and introduced offline web applications (Pham, 2023).


The revolutionary transformation of the internet world regarding web browsers isn't something that took a few days, or even a few years - this process took decades of development to get us to where we are today. It is thanks to big names like Tim Berners-Lee and companies like IBM, Netscape, and Microsoft for the major developments which took place in the crucial decades of the 60s to the early 2000s. The way people interacted with computers was forever changed and, today, the internet allows us to not only connect to others across the globe but also use efficient search engines to browse the web and access important information.
